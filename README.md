  # 📎 Фоторедактор: наложение фото на фото

![Лицензия](https://img.shields.io/badge/license-Free-green)
![Офлайн](https://img.shields.io/badge/работает-офлайн-blue)
![Без установки](https://img.shields.io/badge/установка-не_нужна-orange)

Бесплатное веб-приложение для наложения фотографий друг на друга прямо в браузере. **Работает полностью офлайн** — никаких серверов, никаких загрузок в интернет, все данные остаются на вашем устройстве.

## ✨ Возможности

- 🖼️ **Базовое фото** — перетащите первое изображение как фон
- 🎨 **Наложение поверх** — добавляйте сколько угодно фото поверх
- 📍 **Позиционирование** — перетаскивайте мышкой в любую точку
- 📐 **Изменение размера** — тяните за уголки и стороны
- 🔄 **Поворот** — от -180° до +180°
- 👁 **Прозрачность** — от 5% до 100%
- 🔒 **Сохранение пропорций** — опциональная блокировка
- ↶ **Отмена / Повтор** — до 40 шагов истории
- 🗂 **Слои** — управление порядком, видимость
- 💾 **Экспорт** — JPEG / PNG / WebP с контролем размера
- 🖨 **Печать** — прямая печать результата
- 📋 **Ctrl+V** — вставка из буфера обмена

## 🎯 Как использовать

1. **Перетащите первое фото** на холст — оно станет базой
2. **Перетащите второе фото** — оно ляжет поверх в точке сброса
3. **Двигайте мышкой** — позиционируйте как нужно
4. **Тяните за уголки** — меняйте размер
5. **Нажмите «💾 Скачать»** — сохраните результат

## 🔒 Приватность

## 🚀 Запуск

Просто откройте `index.html` в любом современном браузере:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

Или используйте онлайн-версию: **[Ссылка на GitHub Pages](https://ВАШ-НИК.github.io/photo-overlay-editor/)**

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Ctrl + V` | Вставить фото из буфера |
| `Ctrl + S` | Сохранить результат |
| `Ctrl + Z` | Отменить действие |
| `Ctrl + Shift + Z` | Повторить действие |
| `Delete` | Удалить выбранный слой |
| `Escape` | Снять выделение |
